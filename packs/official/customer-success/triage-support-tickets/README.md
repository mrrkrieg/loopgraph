# Triage and Escalate Support Tickets

This official Loopgraph App turns the original Support Ticket Triage example into an installable, provider-neutral Hermes capability.

It reads support demand, joins approved account context, classifies urgency, prepares internal routing and a customer-response draft, and escalates high-risk cases. Installation is write-blocked; ticket changes and internal notifications require approval, while public sending is not granted by the pack.

The pack includes guided setup, an Intercom + HubSpot + Slack recipe, deterministic safety fixtures, and outcome metrics for triage latency, first-response SLA, escalation precision, and human review burden.

The legacy runnable example remains under `examples/support-ticket-triage` for advanced LoopSpec users. This pack is the marketplace source of truth for new installations.
