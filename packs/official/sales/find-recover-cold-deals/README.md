# Find and Recover Deals Going Cold

This Sales App gives Hermes a governed route from opportunity changes to evidence-backed deal recovery and pipeline learning.

It includes five cooperating loops:

1. Deal Risk Detection identifies stalled stages, close-date slips, silent champions, and activity gaps.
2. Missing Next Step Detection verifies whether a dated, owned buyer or seller commitment exists.
3. Stakeholder Analysis finds verified champion, decision-maker, and multithreading gaps.
4. Deal Follow-Up prepares exact CRM updates, internal briefs, and customer-facing drafts for approval.
5. Pipeline Outcome Learning measures re-engagement, meetings, stage progression, loss, and forecast outcomes.

Supported stack recipes:

- HubSpot + Gmail + Google Calendar + Slack
- Salesforce + Outlook + Microsoft Calendar + Teams

The app starts in shadow mode. Hermes reads only bounded deal-related evidence, never sends messages, never changes a forecast, and never modifies the CRM without exact prepared-action approval. Ambiguous opportunity identity, ownership, stakeholder roles, or commitments cause Hermes to abstain.

Primary value measures are deal-risk precision, re-engagement, meetings booked, stage progression, forecast accuracy, false-positive rate, and human review burden.
