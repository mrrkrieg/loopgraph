# Qualify and Route Inbound Leads

Hermes receives inbound lead events and decides which installed loop should handle each business problem. The app researches the account, evaluates fit and intent, routes clear cases, abstains when identity or ownership is ambiguous, prepares bounded follow-up, and returns meeting and pipeline outcomes as shared evidence.

The default stack is HubSpot, Gmail, and Slack. A second preset provides the same logical capabilities through Salesforce, Outlook, and Teams. Provider-specific fields do not leak into loop logic; connector recipes and confirmed field mappings translate them at the boundary.

Installation starts in shadow mode. CRM changes require exact prepared-action approval. Customer-facing sending and money movement are forbidden by the pack.
