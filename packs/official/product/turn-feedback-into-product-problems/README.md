# Turn Customer Feedback Into Validated Product Problems

This Product App gives Hermes a governed route from customer feedback to validated problems and release learning.

It includes five cooperating loops:

1. Feedback Clustering joins repeated feedback into durable themes.
2. Product Problem Validation tests whether a theme represents a real problem for a defined workflow and segment.
3. Bug Clustering separates recurring defects from onboarding, support-process, and usability problems.
4. Roadmap Evidence prepares an evidence brief and exact issue proposal without changing priority.
5. Release Learning compares post-release usage and support evidence with the original problem hypothesis.

Supported stack recipes:

- Intercom + PostHog + Linear
- Zendesk + Amplitude + Jira

The app starts in shadow mode. Issue creation and updates require approval. Hermes must abstain when identity, product area, segment, evidence quality, or route ownership is ambiguous. No pack can make roadmap commitments or customer promises.

Primary value measures are validated-problem precision, time from recurring feedback to an accountable decision, post-release adoption change, support-volume change, and human review burden.
