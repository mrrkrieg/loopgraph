# Triage GitHub Issues Safely

This official Loopgraph App packages the original GitHub Issue Triage example as a governed, installable Hermes capability.

It reads a new issue, applies repository policy, prepares classifications and labels, escalates possible security reports, and records reviewer corrections as evidence. Installation never enables issue mutations or public replies; those remain exact, approval-bound actions.

Included:

- one issue-intake and triage loop;
- a Hermes technical-triage skill;
- a GitHub + Linear + Slack connector recipe;
- guided repository, ownership, severity, and escalation setup;
- the complete deterministic marketplace safety suite;
- app-level latency, escalation, and review-burden metrics.

The legacy runnable example remains under `examples/github-issue-triage` for low-level LoopSpec teaching. This pack is the marketplace source of truth for new installations.
