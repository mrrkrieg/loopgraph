# Run Engineering Issue and Incident Operations

This Engineering App gives Hermes six governed routes: issue triage, issue-to-plan, incident response, customer impact, release readiness, and incident learning.

It supports GitHub + Linear + Slack and GitLab + Jira + Teams. Hermes preserves issue and incident identity, severity evidence, ownership, customer impact, verifier results, deployments, and recurrence. It may prepare exact project or communication actions for approval, but cannot merge code, deploy, change severity, publish incident communication, or close work autonomously.

Primary outcomes are triage latency, plan acceptance, incident acknowledgement and resolution, customer-impact accuracy, release regression, recurrence, and review burden.
